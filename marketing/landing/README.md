# Landing page scaffold (outline only; not built, not deployed)

This folder is **structure and copy outline** for a future marketing site. There is no site, no
domain, no hosting and no analytics today. A real SEO audit (FITq-style or equivalent) can only
be run after the site is live; see `../seo-and-growth.md` section 0 and the launch gates in section 9.

- `outline.md`: page-by-page structure, section order, headline/copy outline, CTAs, on-page SEO
  fields (title, meta description, H1, schema) and the claims that are and are not allowed.
- `calculator-spec.md`: specification and worked example for the reproducible recovery calculator
  (the lead magnet).

Hard rules for anything built from this outline: no invented metrics, testimonials, logos or
certifications; every number cited or labeled as an illustration/assumption; pre-product status
visible; B2B audience only.
