Security status

We would rather tell you what is missing than imply a posture we do not have.

Real customer data is not accepted until the items under "Not yet" are done.

Built into the prototype

  • Per-tenant API keys (hashed at rest, shown once at issue), with tenant isolation on every request.
  • Bounded request and upload sizes; parsing runs in a separate, resource-limited worker process.
  • Hash-locked dependency pins and dependency/security scanning in CI.
  • The demo UI keeps keys in memory only and sets a strict content security policy.

Not yet

  • Independent third-party security assessment or penetration test.
  • Any compliance certification or attestation.
  • Malware scanning of uploads; rate limiting / WAF.
  • A data retention and deletion policy; production hosting.
  • Reviewed legal terms (our privacy, terms and cookie pages are drafts).
