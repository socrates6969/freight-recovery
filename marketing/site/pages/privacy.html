Website privacy information

This page describes the scoup.ai public website. It is not a privacy policy for a hosted product; no hosted product or customer account is offered.

This website

The pages are static. The site contains no web forms, account registration, analytics code, advertising pixels, or embedded third-party content. Project files contain no scripts, and the site does not set cookies or use browser storage.

The site is hosted with GitHub Pages. GitHub describes its own data handling in the GitHub General Privacy Statement at https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement. The scoup.ai project does not control GitHub's hosting logs or retention.

Email

The contact link opens an email to the project. If you choose to send one, the project receives the address and message you submit and uses them to reply. Do not email shipment documents, customer data, driver data, credentials, or other confidential material.

For a privacy question about an email you sent to the project, write to __CONTACT_EMAIL__. The project is pre-product and has no customer upload or account system.
